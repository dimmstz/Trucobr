# Segurança — requisitos mínimos

- Não incluir chaves privadas, service-role keys ou segredos no APK.
- Aplicar Row Level Security em tabelas expostas ao cliente.
- Validar autenticação e autorização no servidor.
- Usar embaralhamento criptograficamente seguro no servidor.
- Não transmitir cartas ocultas a clientes que não podem vê-las.
- Validar ordem de turno, jogada permitida e tempo de ação no servidor.
- Proteger comandos contra repetição e duplicidade.
- Registrar eventos relevantes e movimentações virtuais.
- Implementar limites de requisição e mecanismos de denúncia.
- Não implementar Pix, saques, depósitos ou conversão monetária nesta fase.
